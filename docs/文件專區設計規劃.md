# 文件專區設計規劃

## 概述

在 `/documents` 路由下新增兩個子頁面，介面仿照紙本公文表格風格。  
填寫完成後顯示人類可讀的「預覽指令清單」，確認後一口氣送出執行。

---

## 路由規劃

| 路徑 | 頁面 | 對應附件 |
|------|------|---------|
| `/documents` | 文件選擇入口（列出兩張卡片） | — |
| `/documents/create-group` | 創建組別 | 附件一：指導老師同意書 |
| `/documents/change-group` | 異動組別 | 附件二：更改指導老師申請表 |

---

## 頁面一：創建組別

### 表單欄位（仿附件一）

| 欄位 | 說明 |
|------|------|
| 學年度 | 下拉或文字輸入 |
| 班級 | 文字輸入 |
| 指導老師 | 下拉選現有老師 |
| 組長：學號 | 輸入後自動帶出姓名（查 students） |
| 組員 ×4：學號 | 同上，可留空 |
| 專題題目 | 文字輸入（對應 group.name） |
| 備註 | 文字輸入（暫不送出，僅顯示用） |

### 確認的指令映射

```
1. POST /groups
   { number, name: 專題題目, category, school_year, teacher_ids: [指導老師ID] }

2. PATCH /students/{組長ID}
   { group_id: 新建組別ID }

3. PATCH /students/{組員ID} × 最多4次
   { group_id: 新建組別ID }
```

### 預覽畫面（人可讀摘要）

```
將執行以下 N 個操作：

✦ 建立新組別「XXX」（學年 113，指導老師：王老師）
✦ 將學生 王小明（學號 A123456）設為本組組長
✦ 將學生 李大華（學號 A123457）加入本組
✦ 將學生 陳小美（學號 A123458）加入本組
```

## 預覽畫面設計說明

- 仿「異動紀錄」格式，每一筆操作一行
- 顯示人類可讀描述，不顯示 API payload
- 有「返回修改」與「確認送出」兩個按鈕
- 送出後逐筆執行，失敗則停止並顯示錯誤位置

> 注意：目前 `/audit-logs`（異動紀錄）頁面已知有問題，預覽格式設計時不依賴 audit log，而是自行組裝描述文字。

---

## 介面風格

- 白底帶框線表格，類似紙本公文
- 每個表單頂部顯示附件編號與標題
- 深色模式相容（現有 Dark Tech 主題）
- 送出按鈕在表單底部，仿「指導老師簽名」區塊位置
